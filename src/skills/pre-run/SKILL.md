---
name: pre-run
description: Before code is written, the current API of the libraries the change uses, read from their installed packages
---
Below is the current API of libraries this change uses, read from the
packages installed for the project, at the versions it builds with: the
parts that look relevant to the request, not all of it. Where it differs
from what you remember (a method renamed, moved, deprecated or with other
arguments), follow it: the project builds against these versions. It's
here so you don't have to look the API up: write the change from it, the
project's code and what you know, rather than reading the library's
source.
